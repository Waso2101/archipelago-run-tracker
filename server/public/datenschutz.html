Privacy

In short: this site is a private hobby project. No tracking, no ads, nothing is loaded from other servers.

personWho runs it

{{SITE_OWNER}}, as a private, non-commercial project for an Archipelago group.

dnsWhen you open the site

To deliver the page the server processes your IP address. No access logs are stored. After failed login attempts the server keeps the IP address in memory for at most 15 minutes to slow down password guessing.

Fonts and icons are served from this server. Nothing is loaded from Google or other third parties.

sports_esportsGame data shown

The tracker shows what happens in the group's Archipelago rooms: player names (Archipelago slot names), games, progress, items, hints, deaths and the room log. This comes from the Archipelago room and the public tracker API of archipelago.gg, fetched by the server, not by your browser.

Runs marked as tests are only visible after logging in.
